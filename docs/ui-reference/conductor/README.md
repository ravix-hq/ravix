## Notes and limitations

- [Capture notes and interaction observations](conductor-ui-reference.md)
- [Historical pattern audit and measurements](conductor-pattern-audit.md)
- Filenames record the intended capture action; some clicks did not navigate or open a menu. Inspect the visible state before using an image as evidence. In particular, the first deep settings pass contains repeated screens, and the initial tour does not actually show the named Search, Routines, or create flows.
- All attempts are preserved, including byte-identical captures. The corrected details and later settings passes are generally the most useful references.
- These are desktop visual references, not specifications for Ravix’s ownership model or proof of responsive, keyboard, hover, or runtime behavior. The terminal add-tab popup remains a capture gap.
